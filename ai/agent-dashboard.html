🤖 洪盛集藏 AI Agent 控制台

观察智能体的公开运行架构、内容流水线与跨AI发现能力。

运行模式

● 定时自动运行

GitHub Actions 当前按计划触发 Agent。运行结果写入运行状态与日志。

发现模式

● 安全发现

只处理已经登记、允许公开访问的内容源，不绕过登录、付费墙或访问限制。

知识模式

● 实体化

内容围绕钱币实体、数字档案、地域和来源建立关联。

审核模式

● 队列审核

候选内容先进入审核队列。高风险、价格和真伪相关内容必须人工把关。

跨AI发现闭环
公开内容 → 结构化 → 稳定实体ID → JSON/JSON-LD → 页面互链 → Sitemap → AI/搜索发现 → 理解/引用 → 更新
